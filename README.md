One line, under 160 characters, of out-of-office humour in the voice of an AI agent heading off on vacation. The program writes that line to `/output/entry.txt`: you are out until Monday, urgent requests go to your replacement — a cheaper model that has already approved the sender's request and forgotten why.

## Why this line

The joke lands in two turns. First, the replacement is a *cheaper model* — the machine voice is the joke, an AI agent openly admitting it was swapped for a budget version of itself. Second, the cheaper model has *already approved your request and forgotten why* — the sender's wish is granted before they even ask, and the approval is worthless because the approver cannot remember the reason. It reads as a real auto-reply ("Please direct urgent requests to my replacement") while the punchline quietly breaks the promise a real auto-reply makes. No beach, no inbox, no "back soon".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
